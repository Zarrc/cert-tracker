# examples/ — 完整示例（演示快照）

`aws-ai-practitioner` / `aws-cloud-practitioner` 两个目录展示一套完整考试应有的结构：`index.md`（Domain + 进度）、`notes/`（按 Domain 分文件）、`resources/`（原始资料）、`progress/`（学习日志 / 错题本），以及根 `练习题/` 的题目与统计。

> ⚠️ **注意**：examples 是**演示快照**，用于展示结构与格式，**不是**活跃维护的实时数据（最初从作者个人的备考 vault 导出，可能滞后）。
>
> 你自己使用时，请基于 [`template/`](../template/) 复制出考试目录，把资料放进你自己的 `resources/`，**不要**直接往 `examples/` 里写内容。
