## 训练超参数

| 参数 | 说明 |
|------|------|
| **Epoch** | 完整遍历数据集的次数 |
| **Batch Size** | 每次参数更新使用的样本数 |
| **Learning Rate** | 控制训练速度 |

## 训练问题与对策

| 问题 | 表现 | 对策 |
|------|------|------|
| **Overfitting（过拟合）** | 训练集好，测试集差 | 更多样化的数据、正则化 |
| **Underfitting（欠拟合）** | 训练集和测试集都差 | 更多 Epoch、更复杂的模型 |
| **Bias/Fairness** | 模型有偏见 | 使用多样、有代表性的数据 |

## Fine-Tuning 方法

| 方法 | 说明 | 风险 |
|------|------|------|
| **Fine-Tuning** | 用标签数据调整预训练模型权重 | Catastrophic Forgetting（灾难性遗忘） |
| **Domain Adaptation** | 针对特定领域调优（法律/医疗） | — |
| **Instruction-Based** | 用标注示例改进特定任务 | — |
| **Continued-Pretraining** | 用无标签数据扩展知识 | — |
| **Transfer Learning** | 将通用特征迁移到新问题 | — |

## 部署选项

### SageMaker 推理

| 方式 | 适用场景 |
|------|---------|
| **Real-Time** | 低延迟、持续流量、自动扩缩 |
| **Batch Transform** | 大批量异步数据 |
| **Asynchronous** | 长运行、大负载 |
| **Serverless** | 间歇流量、自动伸缩 |

### Bedrock 部署

| 方式 | 适用场景 |
|------|---------|
| **On-Demand** | 按 Token 付费，低/零星用量 |
| **Provisioned Throughput** | 预留容量，适合微调模型 |
| **Bedrock Agents** | 多步骤工作流 + Kendra/Lambda |

### 实例类型
- **Inf1/Inf2**：AWS Inferentia（专用推理芯片）
- **P4**：A100 GPU
- **G5**：NVIDIA GPU
- **Graviton2**：ARM 架构（成本优化）
