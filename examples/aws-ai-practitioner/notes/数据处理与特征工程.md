# Domain 2: 数据处理与特征工程

> 权重 18% · 对应资源：freeCodeCamp 15h 课程 (01:16:47)

---

## ML 流水线中的数据处理

```
收集数据 → 预处理 → 特征工程 → 训练 → 部署 → 监控
```

## 数据收集
- **存储**：Amazon S3
- **外部数据**：AWS Data Exchange
- **ETL 工具**：AWS Glue
- **标注**：SageMaker Ground Truth（人工标注）

## 数据预处理

| 步骤 | 说明 | 工具 |
|------|------|------|
| 清洗 | 去重、去 PII | AWS Glue Transformations、Macie |
| EDA | 探索性数据分析 | Glue DataBrew |
| 分割 | 训练(80%) / 验证(10%) / 测试(10%) | 自动 |
| 转换 | 标准化、降维 | SageMaker Autopilot（自动） |

### Glue 生态
- **DataBrew**：可视化数据准备，可复用"配方"（Recipes）
- **Data Quality**：异常检测、质量规则推荐
- **Data Catalog**：集中元数据存储库

## 特征工程

| 操作 | 说明 |
|------|------|
| **特征选择** | 选择最有预测力的特征 |
| **特征创建** | 从现有数据派生新特征 |
| **特征转换** | 缩放、编码、降维 |

### 关键服务
- **SageMaker Feature Store**：ML 特征的单一真相源
- **SageMaker Autopilot**：自动特征工程 + 模型调优

### 降维技术
- **PCA**（主成分分析）：减少特征数量，保留主要方差

## 数据分割比例

| 数据集 | 比例 | 用途 |
|--------|------|------|
| Training | 80% | 训练模型 |
| Validation | 10% | 调优超参数 |
| Test | 10% | 最终评估 |

## 向量数据库

| AWS 服务 | 用途 |
|----------|------|
| **OpenSearch** | k-NN 向量搜索 |
| **Aurora/RDS PostgreSQL** + pgvector | Embeddings + 相似搜索 |
| **MemoryDB** | 毫秒级向量查询，高吞吐 |
| **DocumentDB** | MongoDB 兼容向量搜索 |
| **Neptune ML** | 图神经网络预测 |
