## 计算（EC2 系列）

### EC2 实例购买选项

| 选项 | 说明 |
|------|------|
| **按需** | 按秒付费，无承诺 |
| **预留 (RI)** | 1/3 年，标准/可转换/计划 3 种 |
| **Spot** | 最高 90% 折扣，随时可能回收 |
| **Dedicated Host** | 物理服务器独享 |
| **Savings Plan** | 按 $/小时承诺，覆盖 EC2/Fargate/Lambda |

### 安全组 vs NACL

| | 安全组 (SG) | 网络 ACL (NACL) |
|---|------------|----------------|
| 层级 | 实例级 | 子网级 |
| 规则 | Allow only | Allow + Deny |
| 状态 | 有状态 | 无状态 |
| 默认 | 拒绝入站，允许出站 | 允许全部 |

### 其他计算
| 服务 | 说明 |
|------|------|
| **Lambda** | 无服务器函数，按调用次数付费 |
| **ECS** | Docker 容器编排 |
| **Fargate** | 无服务器容器（无需管理 EC2） |
| **EKS** | Kubernetes 托管 |
| **Lightsail** | 简单 VPS（适合新手） |
| **Batch** | 批量计算作业 |

## 存储（S3 系列）

### S3 存储类

| 存储类 | 可用性 | 适用场景 |
|--------|--------|---------|
| **S3 Standard** | 99.99% | 频繁访问 |
| **S3 Intelligent-Tiering** | 自动分层 | 访问模式不确定 |
| **S3 Standard-IA** | 99.9% | 低频但急需时快速访问 |
| **S3 One Zone-IA** | 99.5% | 可重建的数据 |
| **S3 Glacier** | 分钟级恢复 | 归档 |
| **S3 Glacier Deep Archive** | 12h 恢复 | 长期归档（最低成本） |

### S3 安全
- **Block Public Access** — 默认阻止公共访问
- **Bucket Policies** — 存储桶级权限
- **Object Lock** — 写一次读多次（WORM）
- **Glacier Vault Lock** — 合规锁定

### Snow 家族
| 设备 | 容量 |
|------|------|
| **Snowcone** | 8-14 TB |
| **Snowball Edge** | 80 TB + 计算 |
| **Snowmobile** | 100 PB（集装箱卡车） |

### 其他存储
| 服务 | 说明 |
|------|------|
| **EBS** | 块存储（EC2 附加磁盘） |
| **EFS** | 共享文件系统（Linux，NFS） |
| **FSx** | 第三方文件系统（Windows FS、Lustre） |
| **Storage Gateway** | 混合云存储桥接 |

## 数据库

| 类型 | AWS 服务 |
|------|---------|
| **关系型** | RDS（MySQL/PostgreSQL/Oracle/SQL Server）、Aurora |
| **NoSQL** | DynamoDB（Key-Value + Document） |
| **缓存** | ElastiCache（Redis/Memcached） |
| **数据仓库** | Redshift（PB 级分析） |
| **图** | Neptune |
| **文档** | DocumentDB（MongoDB 兼容） |
| **分类账** | QLDB（不可变日志） |
| **时序** | Timestream |

### RDS vs DynamoDB

| | RDS | DynamoDB |
|---|-----|---------|
| 类型 | 关系型 | NoSQL |
| 扩缩 | 垂直（升级实例） | 水平（自动） |
| 查询 | SQL | API |
| 场景 | 复杂查询、Join | 高并发、Key-Value |

## 网络

| 服务 | 说明 |
|------|------|
| **VPC** | 虚拟私有网络 |
| **Route 53** | DNS 服务 + 域名注册 |
| **CloudFront** | CDN（内容分发网络） |
| **Direct Connect** | 专线连接本地与 AWS |
| **VPN** | 加密隧道连接 |
| **Global Accelerator** | 全球流量优化 |

### Route 53 路由策略
- **Simple** — 简单 A 记录
- **Weighted** — 按权重分发
- **Latency** — 最低延迟
- **Failover** — 主备切换
- **Geolocation** — 按地理位置
- **Geoproximity** — 按位置 + 偏移量
- **Multi-Value** — 多个 A 记录返回随机 IP
