## 什么是云计算

按需提供 IT 资源，按使用量付费。

### 部署模型

| 模型 | 说明 |
|------|------|
| **云（全公有云）** | 全部在云上运行 |
| **混合云** | 云 + 本地设施互联 |
| **本地部署（私有云）** | 自己管理全部基础设施 |

### 六大优势（AWS）

1. **可变支出变固定支出** — 无需前期巨额投入
2. **规模经济** — 从 AWS 的规模中获益
3. **不再猜测容量** — 按需扩缩
4. **速度和敏捷性** — 几秒内启动资源
5. **停止在数据中心上花钱** — 专注业务而非运维
6. **全球化部署** — 几分钟内全球覆盖

## AWS 全球基础设施

| 组件 | 说明 |
|------|------|
| **Region** | 地理区域，每个 Region 至少 3 个 AZ |
| **Availability Zone (AZ)** | 一个或多个数据中心，之间高带宽低延迟 |
| **Edge Location** | CloudFront 缓存节点，全球 400+ |
| **Local Zone** | 将计算/存储靠近大都市用户 |
| **Wavelength** | 嵌入 5G 网络的 AWS 服务 |

### Region 选择因素
- **合规性** — 数据主权要求
- **延迟** — 离用户近
- **成本** — 各 Region 定价不同
- **服务可用性** — 新服务先在部分 Region 上线

## 责任共担模型

```
客户负责"云中"的安全：
  - 客户数据
  - 平台、应用、身份与访问管理
  - OS、网络、防火墙配置
  - 客户端数据加密

AWS 负责"云本身"的安全：
  - 物理安全（数据中心）
  - 硬件、网络、基础设施
  - 托管服务（S3、RDS、Lambda 等）
```

### 服务类型与责任
- **IaaS**（EC2、VPC）：客户负责更多（OS、安全配置）
- **PaaS**（RDS、Lambda）：AWS 负责更多
- **SaaS**（S3、DynamoDB）：AWS 负责大部分

## 定价模式

| 模式 | 说明 |
|------|------|
| **按需** | 按使用量付费，无长期承诺 |
| **预留实例** | 1 年或 3 年承诺，大幅折扣 |
| **节省计划** | 灵活承诺用量换取折扣 |
| **Spot 实例** | 利用空闲容量，最高 90% 折扣，可中断 |
| **免费套餐** | 前 12 个月部分服务免费 |

## Well-Architected Framework（6 大支柱）

| 支柱 | 关注点 |
|------|--------|
| **卓越运营** | 运行和监控系统，持续改进流程 |
| **安全性** | 保护数据与系统 |
| **可靠性** | 从故障中恢复，按需扩缩 |
| **性能效率** | 高效使用计算资源 |
| **成本优化** | 避免不必要的成本 |
| **可持续性** | 最小化环境影响 |
