## AWS 定价模型

### 计算定价
- **EC2**：按秒计费（实例类型 + 区域 + 购买选项）
- **Lambda**：按调用次数 + 执行时间
- **ECS/Fargate**：按 CPU/内存使用

### 存储定价
- **S3**：按 GB/月 + 请求次数 + 数据传输
- **EBS**：按预置容量（GB/月）
- **Glacier**：按存储量 + 恢复时间

### 数据传输
- **入站**（到 AWS）：免费
- **出站**（从 AWS）：按 GB 收费
- **同 Region 内**：免费（通过私有 IP）

## AWS Organizations

| 功能 | 说明 |
|------|------|
| **Consolidated Billing** | 合并所有账号账单 |
| **SCP** | 组织级权限边界 |
| **OU** | 组织单元（分层管理） |

### 多账号策略的好处
- **Cost Allocation Tags**：按项目/部门拆分成本
- **Volume Discounts**：合并用量获更大折扣
- **AWS CloudTrail**：集中审计

## Support Plan 对比

| 计划 | 价格 | 特点 |
|------|------|------|
| **Basic** | 免费 | 文档 + 健康仪表盘 |
| **Developer** | 按用量 | 业务时间邮件支持 |
| **Business** | 按用量 | 1h 响应 + 架构指导 |
| **Enterprise On-Ramp** | 固定 | 30min 响应 + TAM |
| **Enterprise** | 固定 | 15min 响应 + 专属 TAM |

## 成本优化原则

1. **Right Sizing** — 选择合适规格
2. **弹性** — 用 Auto Scaling 匹配需求
3. **购买选项** — RI/Savings Plan/Spot
4. **存储分层** — 数据移到低成本存储类
5. **监控与分析** — 用 Cost Explorer/Budgets

## AWS Trusted Advisor

| 类别 | 检查项 |
|------|--------|
| **成本优化** | 闲置实例、RI 优化 |
| **性能** | EC2 配置、EBS 吞吐 |
| **安全性** | S3 公开访问、安全组规则 |
| **容错** | 多 AZ、RDS 备份 |
| **限制** | 服务使用限制 |

> Basic 计划只能看 7 项核心检查，Business/Enterprise 可看全部。
