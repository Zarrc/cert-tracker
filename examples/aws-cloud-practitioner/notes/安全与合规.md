## IAM（Identity & Access Management）

### 核心组件

| 组件 | 说明 |
|------|------|
| **User** | 真实个人 |
| **Group** | 用户集合，继承权限 |
| **Role** | 给 AWS 服务或临时访问的权限 |
| **Policy** | JSON 格式的权限文档 |

### 访问 AWS 的三种方式
- **AWS Management Console** — Web 界面（需要密码 + MFA）
- **AWS CLI** — 命令行（需要 Access Key）
- **AWS SDK** — 代码调用（需要 Access Key）

### MFA 选项
| 设备 | 说明 |
|------|------|
| 虚拟 MFA | Google Authenticator、Authy |
| 硬件 TOTP | Key Fob（Gemalto） |
| 硬件 FIPS | GovCloud 专用 |
| 生物识别/U2F | YubiKey |

## 安全服务速查

### 保护
| 服务 | 用途 |
|------|------|
| **WAF** | Web 应用防火墙 (SQL注入、XSS) |
| **Shield** | DDoS 防护（Standard 免费，Advanced 付费） |
| **GuardDuty** | 威胁检测（智能监控异常） |
| **Inspector** | 漏洞扫描（EC2、容器） |
| **Macie** | 敏感数据发现（S3 中的 PII） |
| **Security Hub** | 集中安全状态管理 |

### 加密
| 服务 | 用途 |
|------|------|
| **KMS** | 密钥创建和管理 |
| **CloudHSM** | 专用硬件安全模块 |
| **ACM** | SSL/TLS 证书管理 |
| **Secrets Manager** | 密钥/API Token 轮换管理 |

### 合规
| 服务 | 用途 |
|------|------|
| **Artifact** | 合规报告自助获取（SOC、PCI、ISO） |
| **Config** | 资源配置审计和评估 |
| **CloudTrail** | 账户 API 调用日志（审计） |

## DDoS 防护

```
AWS Shield Standard（免费，自动）
  └── AWS Shield Advanced（付费，$3000/月）
      └── WAF（自定义规则，过滤恶意流量）
```

## 共享责任模型（按服务类型）

| | 客户负责 | AWS 负责 |
|---|---------|---------|
| **EC2 (IaaS)** | OS、安全组、补丁、应用 | 物理硬件、网络 |
| **RDS (PaaS)** | 数据、访问权限 | OS、补丁、备份、容错 |
| **S3 (SaaS)** | 数据、权限设置 | 基础设施、耐久性 |

---

## 考点提示
- 🔑 IAM 四大组件（User/Group/Role/Policy）
- 🔑 区分 CloudTrail（API 日志）vs CloudWatch（性能监控）vs Config（配置审计）
- 🔑 GuardDuty（威胁检测）vs Inspector（漏洞扫描）vs Macie（敏感数据）
- 🔑 共享责任模型：不同服务客户负责的范围不同
