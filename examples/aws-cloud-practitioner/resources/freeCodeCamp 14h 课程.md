# AWS Certified Cloud Practitioner Certification Course (CLF-C02)

> freeCodeCamp 出品的 CLF-C02 全面课程。

## 章节

涵盖以下主题域：
1. Cloud Computing / 云概念
2. IAM（Identity Access & Management）
3. EC2 与实例存储
4. Elastic Load Balancing & Auto Scaling
5. Amazon S3
6. 数据库与分析
7. 其他计算（ECS、Lambda、Docker）
8. 部署与管理基础设施
9. 全球基础设施（Route 53、CloudFront）
10. 云集成（SQS、SNS、Kinesis）
11. 云监控（CloudWatch、CloudTrail）
12. VPC 与网络
13. 安全与合规
14. 机器学习
15. 账户管理、计费与支持
