## Security Best Practices

| Practice | Description |
|----------|-------------|
| **Least privilege IAM** | Minimal permissions |
| **PrivateLink / VPC Endpoints** | Network isolation for SageMaker |
| **KMS Encryption** | At-rest and in-transit |
| **S3 Block Public Access** | Prevent public exposure |

## Responsible AI Principles

1. **Fairness** — Model should not have bias
2. **Explainability** — Decisions should be understandable
3. **Privacy** — Data protection
4. **Robustness** — Model should be stable and reliable
5. **Transparency** — Users should know when AI is used
6. **Accountability** — Someone is responsible for AI behavior
