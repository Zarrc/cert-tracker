# examples/ — Complete examples (demo snapshots)

The `aws-ai-practitioner` / `aws-cloud-practitioner` folders show what a complete exam should look like: `index.md` (domains + progress), `notes/` (one file per domain), `resources/` (raw materials), `progress/` (study log / error log), plus the root `practice-questions/` files and stats.

> ⚠️ **Note:** examples are **demo snapshots** meant to illustrate structure and format. They are **not** actively maintained live data (originally exported from the author's personal study vault; may lag behind).
>
> For your own use, copy an exam folder from [`template/`](../template/) instead, put materials into your own `resources/`, and **do not** write content into `examples/`.
